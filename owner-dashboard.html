Payment Review Checklist

Use these steps when a customer says they have paid.

  1. Search the order using the reference or phone number.
  2. Confirm the transaction in your official Paystack dashboard.
  3. Compare the verified amount with the order amount.
  4. Check the data delivery status before retrying delivery.
  5. Do not mark a payment as successful solely because a customer sent a screenshot.

Delivery Troubleshooting

Before retrying an order.

  • Confirm the order was paid successfully.
  • Confirm the recipient phone number and bundle are correct.
  • Review the order's current delivery status.
  • Use Retry Delivery only if the backend permits it.
  • Check the supplier response or server logs if the retry fails.

Campaign Checklist

Review these items before sending.

1. Recipient list

Confirm that numbers are correctly formatted and that recipients have agreed to receive the messages where required.

2. Message content

Check spelling, pricing, links and the business name. Avoid misleading claims.

3. Cost estimate

Use the existing estimate control before sending. The final charge depends on provider rules and message segmentation.

4. Sending status

Read the server response shown in the campaign status box. Do not assume delivery simply because a request was submitted.
